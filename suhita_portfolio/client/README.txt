SUHITA ROY — ONE-PAGE PORTFOLIO

How to run:
1. Open this folder in VS Code.
2. Open index.html.
3. Right-click index.html.
4. Choose "Open with Live Server".

IMPORTANT:
- index.html now contains Home, About, Education, Skills, Experience,
  Projects and Contact in ONE page.
- Use the navigation menu or scroll normally through the complete portfolio.
- The "View My Resume" button opens assets/RESUME.pdf in a new browser tab.
- Keep the assets folder beside index.html.
- style.css contains the design, responsive layout and animations.
- script.js contains the mobile menu, scroll animations, active navigation,
  skill-bar animation, scroll progress and contact form.
